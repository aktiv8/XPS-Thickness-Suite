# legacy/

`thickogram_v1_3.py` is the original standalone Thickogram script from the
`aktiv8/Thickogram` repository (`THickogram_v1_3.py`), kept here **unmodified** for provenance.

It is not used by the suite. The maths and the nomogram drawing were rewritten in
`../thickogram.py` (solver validation, embedded plot, corrected red line) and are tested against this
script's results in `../tests/test_thickogram.py`.
